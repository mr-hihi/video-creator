## Projects

### TC-FS-01: Create a project
- **App:** Frontend
- **Precondition:** C1, C2 and VT1 exist. Settings `filmStudioImageProvider` and `filmStudioClipProvider` at their
  default `null`, the `image` and `video` routes at their default `google_flow`.
- **Steps:**
  1. Navigate to http://localhost:5071/films
  2. Click `New project`
  3. Fill `Name` with `Harbor Mysteries`; fill `Premise` with `A fishing town hides a drowned city.`
  4. Select `English` from `Language`; keep `Landscape 16:9`; select `Anime` from `Style`
  5. Select `6 s` from `Default clip length`
  6. Keep `Characters speak in clips` and `Narration` on; select `narrator-en` from `Narrator voice`
  7. Tick `Background music`; pick `Mai` and `Old Harbor` in `Cast`
  8. Click `Create`
- **Expected:**
  - Step 2: `Photorealistic` is preselected in `Style`, `8 s` in `Default clip length`, `Background music` is off;
    `Default clip length` offers `4 s`, `6 s`, `8 s`, `10 s`, `15 s`, `20 s`, `30 s` in that order;
    no `Images with` or `Clips with` field — the line `Images with: Google Flow · Clips with: Google Flow` with
    a link `Change` → `/settings?tab=film-studio` sits under `Cast`
  - URL becomes `/films/{id}`; `Settings` shows the values entered; `Cast` shows `Mai` and `Old Harbor`,
    both with badge `Different style` (their style is `Photorealistic`)
  - `GET F/projects/{id}` → `status` = `active`, `orientation` = `landscape`, `styleId` = `anime`,
    `clipDurationS` = 6, `allowMusic` = `true`, `flowProjectId` = `null`, `storyBible` = `null`,
    `storyBibleEpisodeId` = `null`, `storyBibleUpdatedAt` = `null`; no image or clip provider field
  - `/films` lists `Harbor Mysteries` with badge `16:9`, `Anime` and `0 episodes`

  body changed as follows — from step 3 on also with `"name":"Second Series"`, so the duplicate name does not
  answer first:

  2. `"name":"test series"`

  7. `HTTP 422`
  8. `HTTP 400`, `detail` = `Description must be at most 5000 characters`
  - `GET F/projects` still lists one `Test Series`

### TC-FS-67: Edit the story bible
- **App:** API
- **Precondition:** P1 whose `storyBible` was written by episode E1 (`storyBibleEpisodeId` = E1); no episode of
  P1 is `running`.
- **Steps:** `curl -i -X PATCH F/projects/{P1} -H 'Content-Type: application/json' -d '{body}'`:
  1. `{"storyBible":"{20001 × a}"}`
  2. `{"storyBible":"Mai lost her father at sea. She has a sister."}`
  3. `{"storyBible":"{20000 × a}"}`
  4. `curl -s -X POST F/projects -H 'Content-Type: application/json'` with P1's body plus
     `"name":"Bible Series","storyBible":"Seed"`
- **Expected:**
  1. `HTTP 400`, `detail` = `Story bible must be at most 20000 characters`; the story bible is unchanged
  2. `HTTP 200`, `storyBible` = the new text, `storyBibleEpisodeId` = `null`, `storyBibleUpdatedAt` = now
  3. `HTTP 200`
  4. `HTTP 201`, `storyBible` = `null` — a project starts with no story bible

## Character library

### TC-FS-05: Create, edit, find and delete a character
- **App:** Frontend
- **Steps:**
  1. Navigate to http://localhost:5071/films/library
  2. Click `New character`; fill `Name` with `Captain Bao`, select `character` from `Type`, fill
     `Description` with `A stocky sea captain with a grey beard and a navy coat`; leave `Image prompt`
     blank; fill `Voice description` with `Low, slow voice with a coastal accent`; keep `Photorealistic`;
     click `Save`
  3. Open `Captain Bao`
  4. Change `Description` to `A stocky sea captain with a white beard`; click `Save`
  5. Type `bao` in the search field; select `location` in the type filter; select `character` again
  6. Open `Captain Bao`; click `Delete`; click `OK`
- **Expected:**
  - The tab shows the hint `Generate reference images from a project's Cast panel.`
  - Step 3: `Image prompt` starts with `Reference image of A stocky sea captain with a grey beard and a navy coat.`
    and contains the `Photorealistic` style instruction and lighting
  - Step 4: `Image prompt` is unchanged (still `grey beard`)
  - Step 5: `bao` shows one card; the `location` filter shows none of it
  - Step 6: dialog `Delete character 'Captain Bao'?`; the card disappears; `GET F/characters?q=bao` → `[]`

### TC-FS-06: Character rules

- **Expected:**

### TC-FS-07: Reference image — generate, edit, upload
- **App:** API unit + API
- **Precondition:** P1 with C1 (`character`) and C2 (`location`) linked, both references `none`; C3 `Ghost`
  in the library, not linked.
- **Steps:**
  1. *(API unit, fake provider)* `generate-reference` for C1 and for C2 in P1, run the worker
  2. *(API unit)* `generate-reference` for C1 again while its request is `queued`
  3. `curl -i -X POST F/projects/{P1}/characters/{C3}/generate-reference`
  4. `curl -i -X POST F/projects/{P1}/characters/{C2}/edit-reference -H 'Content-Type: application/json' -d '{"prompt":"   "}'`
  5. `curl -i -X POST F/characters/{C2}/reference -F 'file=@notes.txt'` (from `video-tool/`)
  6. `curl -i -X POST F/characters/{C2}/reference -F 'file=@api/tests/fixtures/films/big.png'`
  7. `curl -i -X POST F/characters/{C2}/reference -F 'file=@api/tests/fixtures/films/landscape.png'`
- **Expected:**
  1. Two `character_image` requests with `provider` = `google_flow`; C1's `params.aspect` = 9:16, C2's = 16:9;
     prompts = their `image_prompt`; after the worker both references are `done`, `referenceSource` =
     `generated`, files under `api/storage-test/films/characters/{id}/`
  2. `HTTP 409`, `detail` = `Character 'Mai' has generation running`
  3. `HTTP 409`, `detail` = `Character 'Ghost' is not in this project`
  4. `HTTP 400`, `detail` = `Edit prompt must be 1-2000 characters`
  5. `HTTP 400`, `detail` = `Unsupported image type '.txt'. Use one of: .jpeg, .jpg, .png, .webp`
  6. `HTTP 413`, `detail` = `Image exceeds 20 MB`
  7. `HTTP 200`, `referenceStatus` = `done`, `referenceSource` = `uploaded`, `providerMedia` = `null`
