## Requests

### TC-FS-22: What each request sends
- **App:** API unit
- **Precondition:** Fake provider recording calls. Custom style `Film Still` with `scenePrefix`
  `Cinematic still,`; P1 uses it with `language` `en`, `landscape`, `clipDurationS` 8, VT1 as narrator.
  C1 `Mai` (`voiceDescription` `Soft, quick voice`) and C2 `Old Harbor` (no voice), both references `done`.
  Scene S1: `imagePrompt` `Mai stands on the pier`, `videoPrompt`
  `0-3s: Mai walks. 3-6s: She stops. 6-8s: She looks up.`, characters [C1, C2], `narratorText`
  `The fog never lifts here.`, `clipDurationS` 8, image `done`; the fake provider makes 8 s clips.
- **Steps:**
  1. `generate-image` on S1
  2. `generate-clip` on S1 with `allowDialogue` `true`
  3. `generate-clip` on S1 with `allowDialogue` `false`
  4. Set S1 `videoPrompt` to `0-3s: Mai walks. Audio: waves crash.`; `generate-clip` with `allowDialogue` `true`
  5. `generate-narration` on S1
- **Expected:**
  1. `kind` = `scene_image`, `mediaKind` = `image`, `provider` = `google_flow`, prompt
     `Cinematic still, Mai stands on the pier`; inputs = the references of C1 and C2; `params.aspect` = 16:9
  2. Prompt = the three lines `0-3s: Mai walks. 3-6s: She stops. 6-8s: She looks up.` /
     `Character voices: Mai: Soft, quick voice.` /
     `Audio: no background music. Keep character dialogue and natural ambient sounds.`; input = S1's image;
     `params` clip length 8, aspect 16:9, no segments
  3. No `Character voices:` line; last line
     `Audio: natural ambient sounds only, no background music, no narration, no voiceover.`
  4. `Character voices: Mai: Soft, quick voice.` is kept; no `Audio:` line is added
  5. `kind` = `narration`, `mediaKind` = `speech`, provider = the speech provider; prompt
     `The fog never lifts here.`; inputs = VT1's sample with its `sampleText`; `params.language` = `en`

### TC-FS-23: Retry rules
- **App:** API unit
- **Precondition:** One `scene_image` request; the fake provider answers as listed, then succeeds.
  `FILM_REQUEST_MAX_ATTEMPTS` = 5.
- **Steps:** run the worker with each provider answer:
  1. `Media not found` once
  2. `Extension disconnected` once
  3. `[HIJACK] extension_hijack_detected` once
  4. `CAPTCHA_FAILED` every time
  5. `PUBLIC_ERROR_UNUSUAL_ACTIVITY`
  6. `UNSUPPORTED_ON_BATCH_API`
  7. A content-filter block
  8. `Internal error` every time
- **Expected:**
  1. Inputs are uploaded again; the retry succeeds; `attempts` = 0
  2. Back to `queued`, then `done`; `attempts` = 0
  3. Same as 2
  4. `failed` after the 10th attempt
  5. `failed` at once; no other `google_flow` request is submitted for 120 s
  6. `failed` at once
  7. `failed` at once
  8. Waits 20 s, 40 s, 80 s, 160 s between tries (`nextAttemptAt`); `failed` after the 5th attempt

## Scene state

### TC-FS-26: Downstream resets
- **App:** API unit
- **Precondition:** A `paused` episode; S1 has image, clip (trim 1500 / 6500) and narration `done`, and a
  `clip-segments/` folder left by a failed request; S2 has image `done`.
- **Steps:**
  1. Upload IMG-L as S1's image
  2. `PATCH` S1 `{"narratorText":"A new line"}`
  3. `PATCH` S2 `{"imagePrompt":"Wider shot"}`
  4. `PATCH` S2 `{"clipDurationS":20}`
  5. Mark the episode `done`; `PATCH` S2's trim; read the episode
- **Expected:**
  1. S1 `imageSource` = `uploaded`, `clipStatus` = `none`, `clip.mp4` and `clip-segments/` deleted,
     `trimStartMs` = 1000, `trimEndMs` = `null`; narration still `done`
  2. S1 `narrationStatus` = `none`; its narration file deleted
  3. S2's statuses unchanged
  4. S2 `clipDurationS` = 20; its statuses unchanged
  5. `needsAssembly` = `true`

### TC-FS-28: Add, edit, move and delete scenes
- **App:** API + API unit
- **Precondition:** A `paused` episode with S1, S2, S3 at positions 0, 1, 2; C3 in the library, not linked to
  the project.
- **Steps:** with `{p}` = `{"imagePrompt":"Close-up of the bell","videoPrompt":"0-3s: The bell sways."}`:
  1. `POST F/episodes/{id}/scenes` `{p}` plus `"afterPosition":0`
  2. Same with `"afterPosition":-1`
  3. Same without `afterPosition`
  4. Same with `"imagePrompt":""`
  5. `PATCH F/scenes/{S1}` `{"narratorText":"{1001 × a}"}`
  6. `PATCH F/scenes/{S1}` `{"characterIds":["{C3}"]}`
  7. `PATCH F/scenes/{S1}` `{"position":99}`
  8. `DELETE` the scene at position 1
  9. *(API unit)* `POST` a scene to an episode that has 80
  10. *(API unit)* `PATCH` a scene of a `running` episode
  11. *(API unit)* `generate-image` twice on one scene
  12. `PATCH F/scenes/{S2}` `{"clipDurationS":45}` — S1 is gone after step 8
  13. `PATCH F/scenes/{S2}` `{"clipDurationS":3}`
- **Expected:**
  1. `HTTP 201`, `position` = 1; S2 and S3 move to 2 and 3
  2. `HTTP 201`, `position` = 0; every other scene moves down one
  3. `HTTP 201`, at the last position; every status `none`, `trimStartMs` = 1000, `clipDurationS` = the
     project's
  4. `HTTP 400`, `detail` = `Image prompt must be 1-4000 characters`
  5. `HTTP 400`, `detail` = `Narration must be at most 1000 characters`
  6. `HTTP 400`, `detail` = `Character {C3} is not in this project`
  7. `HTTP 400`, `detail` = `Position must be between 0 and {last}`
  8. `HTTP 204`; positions run 0 … n − 1 without a gap; the scene's folder is removed
  9. 400 `An episode holds at most 80 scenes`
  10. 409 `Episode {number} is running — stop it first`
  11. The second answers 409 `Scene {n} has generation running`
  12. `HTTP 400`, `detail` = `Clip length must be 4-30 seconds`
  13. `HTTP 400`, same `detail`

### TC-FS-50: Cancel a request stuck in the queue
- **App:** API
- **Precondition:** No Google Flow extension connected (`extensionConnected` = `false` in `GET
  http://localhost:5070/settings/providers`); `filmStudioImageProvider` setting `google_flow`. A project P, a linked character C whose
  reference is `none`, no episode of P `running`.
- **Steps:**
  1. `curl -i -X POST F/projects/{P}/characters/{C}/generate-reference`; wait 10 s; `GET F/projects/{P}`
  2. `curl -i -X POST F/requests/{R}/cancel` with `R` = the `id` from step 1; `GET F/projects/{P}`
  3. `curl -i -X POST F/requests/{R}/cancel` again
  4. `curl -i -X POST F/requests/00000000-0000-0000-0000-000000000000/cancel`
- **Expected:**
  1. `HTTP 202`; after 10 s the request is still listed in `openRequests` with `characterId` = C, `status`
     `queued` — or `processing` for under a second while the worker retries — and C's `referenceStatus` = `queued`
  2. `HTTP 200`, `status` = `cancelled`; `openRequests` is empty; C's `referenceStatus` = `none`
  3. `HTTP 409`, `detail` = `Only a queued request can be cancelled`
  4. `HTTP 404`, `detail` = `Generation request 00000000-0000-0000-0000-000000000000 not found`

### TC-FS-31: Providers share the queue fairly
- **App:** API unit
- **Precondition:** Fake providers `google_flow` (1 slot) and `fake-api` (1 slot). Requests created in this
  order: A1 (`google_flow`, episode A), B1 (`google_flow`, episode B), A2 (`fake-api`), A3 (`google_flow`).
- **Steps:**
  1. Run the worker while A1 is held `processing`
  2. Release A1; run again; release each request as it starts
- **Expected:**
  1. A1 and A2 run; B1 and A3 wait for the `google_flow` slot
  2. `google_flow` runs B1 before A3 — oldest first across episodes
