## Creation

### TC-FS-11: Create an episode from an idea and pause after the script
- **App:** Frontend
- **Precondition:** P1 with C1 and C2 linked; the default preset at its current version.
- **Steps:**
  1. Navigate to `/films/{P1}`; click `New episode`
  2. Keep source `Idea`; fill `Idea` with `Mai finds a glowing compass in the harbor fog and follows it to a sunken bell.`
  3. Fill `Target length` with `16`
  4. In `Pause after`, tick `Script` and keep `Scene images` ticked
  5. *(captcha on)* Wait for the captcha; click `Create and start`
  6. Wait until the status badge shows `paused`
- **Expected:**
  - Step 3: the hint reads `The script picks the number of scenes and each one's length, 4-30 s.`
  - URL becomes `/films/{P1}/episodes/1`; `Writing script` is `paused` and the page reads
    `Paused after Writing script — check the work, then Continue.`; a `Continue` button is shown
  - `Scenes` shows at least one card, each with a non-empty `Image prompt` and `Video prompt`, a
    `Clip length (s)` of 4–30, every image, clip and narration status `none`
  - `Script` shows a non-empty logline, `Music prompt` and `Thumbnail prompt`, `Prompt preset` =
    `{default preset name} v{n}`, `Source` = `Idea`
  - `GET F/episodes/{id}` → `status` = `paused`, `step` = `writing_script`, `number` = 1, `targetDurationS` = 16,
    `filmScriptPrompt` = the default preset's current `filmScript`; every scene has `trimStartMs` = 1000
  - Every character a scene lists is in P1's cast

  6. P1, `{"source":"film_analysis","sourceJobId":"{TC-VTM-01 id}"}`
  7. P1, `{"source":"film_analysis","sourceJobId":"{J id}"}`
  8. P1, `{"source":"film_analysis","sourceJobId":"00000000-0000-0000-0000-000000000000"}`
  9. P1, `{"source":"idea","idea":"A storm","presetId":"00000000-0000-0000-0000-000000000000"}`

### TC-FS-13: An episode from a film analysis keeps its own copy

- **Steps:**
  1. `curl -s -X POST F/projects/{P1}/episodes -H 'Content-Type: application/json' -d '{"source":"film_analysis","sourceJobId":"{FA1}","targetDurationS":16,"stopPoints":{"afterScript":true,"afterReferences":true,"afterSceneImages":true}}'`

  `landscape`, `realistic`, `clipDurationS` 8, `allowDialogue` `false`, `allowNarration` `false`; C1 linked
  with `voiceDescription` `Soft, quick voice`; episode 1 has a script, `title` `The Fog`, `logline`
  `Mai hears a bell.`. Faked `claude` runner recording args, working directory and stdin.
- **Steps:**
  1. Run `writing_script` for episode 2: `idea` source, `idea` `The bell rings again`, `targetDurationS` 60
  2. Run it for episode 3: `film_analysis` source from FA1's copies, `idea` `Set it in winter`; the faked reply
     gives a new character `Woman in red coat` with `referenceFrame` = the first copied frame name
- **Expected:**
  1. `--system-prompt` = episode 2's `filmScriptPrompt`; `--json-schema` lists `title`, `logline`,
     `characters`, `scenes` (with `durationS`), `musicPrompt`, `thumbnailPrompt`; `--tools ""`; working
     directory = the system temp folder; the message contains, in order:
     `Series: Test Series`, `Premise: A fishing town hides a drowned city.`,
     `Language of narration and dialogue: English`, `Frame: 16:9 landscape`, `Style: Photorealistic — `,
     `Write scenes whose clip lengths, each minus its first second, add up to about 60s. Give each scene the clip length its action needs, 4-30 s; a typical clip lasts 8s. The first second of every clip is cut, so a scene's narration must fit in its clip length minus 1 s.`,

     `Cast:`, `Mai (character): A young woman in a red raincoat with short black hair. Voice: Soft, quick voice`,

     frame as its reference, `originJobId` = FA1

### TC-FS-16: Script failures
- **App:** API unit
- **Steps:** run `writing_script` with a faked `claude` that:
  1. prints `not json`
  2. answers `{"is_error": true, "result": "Overloaded"}`
  3. answers with no `structured_output`
  4. returns two scenes, both with a blank `imagePrompt`
  5. never answers, with `FILM_SCRIPT_TIMEOUT_SEC` = 1
- **Expected:**
  - Every run: `status` = `failed`, `step` = `writing_script`, no scene saved, `error_message`:
  1. `claude returned output that is not JSON`
  2. `claude failed: Overloaded`
  3. `claude returned no structured output`
  4. `claude returned no scenes`
  5. `claude timed out after 1s`
  - `resume` after run 1 calls `claude` again

## Workflow

### TC-FS-17: Actions allowed per status
- **App:** API unit
- **Precondition:** P1 with `allowNarration` `false`; episode 1 `draft`.
- **Steps:**
  1. `continue`
  2. `start`
  3. `start` again while `running`
  4. `PATCH` `{"title":"New title"}` while `running`
  5. `assemble` while `running`
  6. `stop`; then set P1 `allowNarration` `true` with no narrator voice; then `continue`
  7. Set the episode to `failed` at `generating_clips`; `rewrite-script` while a scene has an image
  8. Set the episode to `paused` with no scene image and one `scene_image` request `processing`; `rewrite-script`
- **Expected:**
  1. 409 `Cannot continue episode 1 while it is draft`
  2. 200, `status` = `running`, `step` = `writing_script`, `startedAt` set
  3. 409 `Cannot start episode 1 while it is running`
  4. 409 `Episode 1 is running — stop it first`
  5. 409 `Cannot assemble episode 1 while it is running`
  6. `stop` → `paused`, `step` kept; `continue` → 409 `Pick a narrator voice for the project or turn narration off`
  7. 409 `Scenes already have images or clips — delete them before rewriting`
  8. 409 `Episode 1 has generation running`; the scenes are kept

### TC-FS-19: Stop with requests in flight

### TC-FS-53: Stop kills the script being written
- **App:** API unit
- **Precondition:** Episode `draft` with no scene and every stop point ticked; the `claude` stand-in is a real
  process that runs until killed.
- **Steps:**
  1. `start`; run the step worker; `stop` while the stand-in runs
  2. `continue`; let the stand-in answer with one scene; run the step worker
- **Expected:**
  1. The stand-in process ends at once; `status` = `paused`, `step` = `writing_script`, `errorMessage` = `null`,
     no scene saved
  2. `claude` is called again and the scene is saved; the episode pauses after `writing_script`

### TC-FS-20: A failing stage and Resume
- **App:** API unit
- **Precondition:** Fake provider fails `scene_image` for scenes 2 and 3 with `Blocked by the content filter`
  and answers scene 1 after a delay; episode at `generating_scene_images` with 3 scenes.
- **Steps:**
  1. Run the worker until idle
  2. Let the provider answer every scene; `resume`; run the worker until idle
- **Expected:**
  1. Scenes 2 and 3 fail at once (`attempts` = 1); the episode stays `running` until scene 1 is `done`, then
     `status` = `failed`, `step` = `generating_scene_images`, `errorMessage` = `2 scene image(s) failed — fix them and resume`
  2. Exactly two new `scene_image` requests, for scenes 2 and 3; the episode moves on to `generating_clips`

### TC-FS-21: Manual screenplay, edits and delete
- **App:** API unit + API
- **Steps:**
  1. *(API unit)* Episode E2 `draft`; add two scenes with `POST F/episodes/{E2}/scenes`; `start` with a stop
     point after references
  2. `PATCH F/episodes/{E1}` `{"idea":"Changed"}` on a `paused` E1
  3. *(API unit)* `PATCH` `{"musicPrompt":"Slow cello"}` on a `done` episode whose music is `done`
  4. *(API unit)* `DELETE` an episode with a `queued` request
  5. `DELETE F/episodes/{E1}`; create another episode in P1
- **Expected:**
  1. `claude` is never called; `writing_script` ends at once and the two scenes are kept
  2. `HTTP 409`, `detail` = `Idea and target length can change only before the episode starts`
  3. `musicStatus` = `none`, the music file is gone, `needsAssembly` = `true`
  4. 409 `Episode {number} has generation running`
  5. `HTTP 204`; the new episode's `number` = P1's `lastEpisodeNumber` before the call + 1 — E1's number is not reused even when E1 had the highest one
