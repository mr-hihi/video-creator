## Audio

### TC-FS-32: What `generating_audio` queues
- **App:** API unit
- **Precondition:** P1 with `allowNarration` `true`, VT1 as narrator, `allowMusic` `true`; an episode at
  `generating_audio`, `musicPrompt` `Slow cello, 60 BPM`, three scenes with kept clip lengths 7000, 7000 and
  5500 ms: S1 `narratorText` `The fog rolls in.` (narration `none`), S2 no `narratorText`, S3 `narratorText`
  `The bell rings.` (narration `done`).
- **Steps:**
  1. Run the stage
  2. Run it again with `allowNarration` `false`, `allowMusic` `true`, `musicPrompt` blank, `musicStatus` `none`
- **Expected:**
  1. One `narration` request, for S1; one `music` request with prompt `Slow cello, 60 BPM` and a minimum length
     of 20 s (19.5 s rounded up)
  2. No request; the stage ends at once

## Assembly

### TC-FS-33: Scene timing and subtitles
- **App:** API unit
- **Precondition:** Real `ffmpeg`; `allowNarration` `true`; three scenes, each clip CLIP-8 with trim 1000 / `null`
  (7000 ms kept). S1 narration NAR-3 (3200 ms), `narratorText` `The fog rolls in.`; S2 narration NAR-8,
  `narratorText` `The bell rings under the water.`; S3 no narration.
- **Steps:**
  1. Run `assembling`
- **Expected:**
  - Scene lengths in the film: S1 3700 ms (3200 + 500), S2 7000 ms (narration cut at the kept end), S3 7000 ms;
    `durationMs` = 17700 ± 100
  - The `.srt` holds two cues: `00:00:00,000 --> 00:00:03,200` `The fog rolls in.` and
    `00:00:03,700 --> 00:00:10,700` `The bell rings under the water.`; none for S3
  - `needsAssembly` = `false`, `status` = `done`; the temporary work folder is gone

### TC-FS-34: Picture, sound and file name
- **App:** API unit
- **Precondition:** Real `ffmpeg`; clips from CLIP-8 (1920×1080). Project `Test Series`, episode 2 titled
  `Race Against Time`.
- **Steps:**
  1. Assemble with `orientation` `landscape`
  2. Assemble the same clips with `orientation` `portrait`
  3. `ffprobe` both outputs
- **Expected:**
  1. File `output/Test Series - E02 - Race Against Time.mp4`
  3. Landscape: 1920×1080; portrait: 1080×1920 with the picture padded, not stretched; both 24 fps, H.264,
     AAC 48000 Hz stereo

### TC-FS-35: Music mix
- **App:** API unit
- **Precondition:** Real `ffmpeg`; a 21 s film; `FILM_MUSIC_VOLUME` = 0.2.
- **Steps:**
  1. Assemble with MUS-5 as the music track
  2. Assemble with MUS-60
- **Expected:**
  - Both outputs last 21 s — music never makes the film longer
  - The music enters the mix at volume 0.2
  1. MUS-5 loops: it plays from 0, 5, 10, 15 and 20 s, the last pass cut at 21 s with the fade-out from 19 s
  2. MUS-60 is cut at 21 s with a fade-out from 19 s

### TC-FS-36: No narration, and burned subtitles
- **App:** API unit
- **Steps:**
  1. Assemble an episode whose project has `allowNarration` `false` (the scenes have narration files)
  2. Assemble an episode with narration used, `burnSubtitles` `true`, `subtitleStyle` `cinematic_gold`
- **Expected:**
  1. No `.srt`; `subtitlesPath` = `null`; the narration files are not mixed in
  2. The `.srt` is written and the cues are burned into the picture with the `cinematic_gold` look

### TC-FS-37: Assembly failures
- **App:** API unit
- **Steps:**
  1. `assemble` a `done` episode after S3's clip was reset to `none`
  2. Run `assembling` with a faked `ffmpeg` exiting with `Invalid data found when processing input`
  3. Run it with `FILM_ASSEMBLY_TIMEOUT_SEC` = 1 and a `ffmpeg` that hangs
  4. `assemble` a `done` episode after a part without scenes was added as part 2
  5. Run it with `FILM_ASSEMBLY_TIMEOUT_SEC` = 2 and a faked `ffmpeg` whose every command takes 1 s, on an
     episode of 6 scenes
- **Expected:**
  - Runs 1–4: `status` = `failed`, `step` = `assembling`; the temporary work folder is gone
  1. `errorMessage` = `Scene 3 has no clip` — `generating_audio` ran first, `generating_clips` did not
  2. `errorMessage` starts with `Assembly failed:` and contains `Invalid data found when processing input`
  3. `errorMessage` = `Assembly timed out after 1s`
  4. `errorMessage` = `Part 2 has no scenes`
  5. `status` = `done` — the limit applies to each command, not to the whole assembly

## Thumbnails & download

### TC-FS-38: Thumbnails
- **App:** API unit + API
- **Precondition:** A `done` episode of a `portrait` project; C1 in 5 scenes, C2 in 3, C3 in 2, C4 in 1.
- **Steps:**
  1. With `thumbnailPrompt` blank: `POST F/episodes/{id}/thumbnails`
  2. Set `thumbnailPrompt` to `Mai holding a glowing compass in the fog`; `POST …/thumbnails`
  3. `POST …/thumbnails` again while those requests are `queued`
  4. `POST F/episodes/{id}/thumbnail` `{"candidate":5}`
  5. `POST …/thumbnail` `{"candidate":2}` while candidate 2 is `queued`
  6. *(API unit)* Let all four finish; `POST …/thumbnail` `{"candidate":1}`
- **Expected:**
  1. `HTTP 409`, `detail` = `Episode {number} has no thumbnail prompt`
  2. `HTTP 202` with four `thumbnail` requests, candidates 1–4, `params.aspect` = 16:9, inputs = the references
     of C1, C2, C3
  3. `HTTP 409`, `detail` = `Thumbnails are already being generated`
  4. `HTTP 400`, `detail` = `Candidate must be 1-4`
  5. `HTTP 409`, `detail` = `Thumbnail candidate 2 is not ready`
  6. `thumbnailPath` = `output/{stem}-thumbnail.jpg`, 1280×720 (`ffprobe`); `needsAssembly` unchanged

### TC-FS-39: Download
- **App:** API
- **Precondition:** A `done` episode with a video, no `.srt` and no chosen thumbnail.
- **Steps:**
  1. `curl -s -D - -o /dev/null 'F/episodes/{id}/download?file=video'`
  2. `curl -i 'F/episodes/{id}/download?file=subtitles'`
  3. `curl -i 'F/episodes/{id}/download?file=thumbnail'`
  4. `curl -i 'F/episodes/00000000-0000-0000-0000-000000000000/download?file=video'`
  5. `curl -i 'F/files/%2e%2e/%2e%2e/api/.env'`
- **Expected:**
  1. `HTTP 200`, `Content-Disposition` attachment with file name `{stem}.mp4`
  2. `HTTP 409`, `detail` = `Episode {number} has no subtitles yet`
  3. `HTTP 409`, `detail` = `Episode {number} has no thumbnail yet`
  4. `HTTP 404`, `detail` = `Episode 00000000-0000-0000-0000-000000000000 not found`
  5. `HTTP 404`

## End to end

### TC-FS-40: From idea to film
- **App:** Frontend *(real provider)*
- **Precondition:** VT1 exists; the providers that `filmStudioImageProvider`, `filmStudioClipProvider` and the
  `speech` route resolve to are ready.
- **Steps:**
  1. Navigate to http://localhost:5071/films; click `New project`
  2. Fill `Name` with `E2E Short`; keep `Landscape 16:9`, `Photorealistic`, `8 s`; untick
     `Characters speak in clips`; keep `Narration` on and select `narrator-en`; click `Create`
  3. Click `New episode`; fill `Idea` with `A paper boat sails across a puddle during a storm.`; fill
     `Target length` with `16`; untick every `Pause after` box
  4. *(captcha on)* Wait for the captcha; click `Create and start`
  5. Wait until the status badge shows `done`
  6. Click `Download video`, then `Download subtitles`
- **Expected:**
  - The stage list ends with all eight stages `completed`, without a pause
  - Opening each part of `Outline`, every scene card shows an image, a clip player and a narration player
  - `Script` shows a non-empty `Summary`; the project's `Story bible` tab reads `Updated by E1 · {time}`
  - `Result` shows a playable film and its duration
  - Step 6: files `E2E Short - E01 - {title}.mp4` and `E2E Short - E01 - {title}.srt`; the `.srt` has one cue per
    scene with narration
