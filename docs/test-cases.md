## Test ID convention

`TC-{ACRONYM}-{NN}`, e.g. `TC-VTM-01`. Numbers are zero-padded and never reused, even after a case is
removed.

## Apps

- **Frontend** — browser on the fenced test stack (http://localhost:5071).
- **API** — `curl` against http://localhost:5070.
- **API unit** — `sh run.sh test`, mocks only, for cases no stable real video can reproduce.
