# 4.1 Projects & library

Part of [4. Film Studio](../4-film-studio.md). A project holds the settings every episode of a series
shares; characters, styles and voice templates live in a library shared by all projects.

## Data model — `FilmProject` (table `film_projects`)

| Field | Type | Meaning |
|---|---|---|
| `id` | string(36) | UUID v4 |
| `name` | string(100) | trimmed; unique, case-insensitive |
| `description` | text \| null | the series premise; sent to every script call (4.2) |
| `language` | enum | `vi` \| `en` \| `ja` — language of narration and dialogue |
| `orientation` | enum | `landscape` (16:9) \| `portrait` (9:16) — every scene image, clip and the film |
| `style_id` | string(40) | → `film_styles.id`; the look of scene images |
| `clip_duration_s` | int | `4` \| `6` \| `8` \| `10`, default `8` — the clip length of a scene added by hand or copied from a film clone, and the typical length the script is told (4.2); each scene keeps its own (4.3) |
| `allow_dialogue` | boolean | default `true` — characters may speak inside clips (4.3 § Prompts sent) |
| `allow_narration` | boolean | default `true` — a narrator reads each scene's `narrator_text` (4.4) |
| `narrator_voice_id` | string(36) \| null | → `film_voice_templates.id` |
| `allow_music` | boolean | default `false` — one background track per episode (4.4) |
| `status` | enum | `active` \| `archived` |
| `last_episode_number` | int | highest episode `number` ever given, default 0 (4.2) |
| `flow_project_id` | string(36) \| null | the Google Flow project its media live in; written and read only by the Google Flow provider |
| `created_at` / `updated_at` | datetime (UTC) | |

### Creation and edit rules

| Rule | Result |
|---|---|
| Request misses a field or holds a value outside an enum | 422 |
| `name` trimmed is 1–100 characters | 400 `Project name must be 1-100 characters` |
| `name` unique, case-insensitive | 409 `A project named '{name}' already exists` |
| `description` at most 5000 characters | 400 `Description must be at most 5000 characters` |
| `styleId` known | 400 `Style {id} not found` |
| `clipDurationS` is 4, 6, 8 or 10 | 400 `Clip length must be 4, 6, 8 or 10 seconds` |
| `narratorVoiceId` known, when given | 400 `Voice {id} not found` |
| Every id in `characterIds` (creation only) known | 400 `Character {id} not found` |
| Edit: `orientation` or `styleId` changes while a scene of the project has an image | 409 `Orientation and style are fixed once a scene image exists` |
| Edit, link, generate on an `archived` project | 409 `Film project {id} is archived` |
| Unknown project | 404 `Film project {id} not found` |

- Creation takes every field above except `status`, `last_episode_number` and `flow_project_id`, plus optional `characterIds`
  to link at once. A new project is `active`.
- `clip_duration_s`, the three `allow_*` flags and the narrator voice can change at
  any time. They apply to requests created afterwards — `clip_duration_s` to scenes created afterwards;
  queued requests keep the provider they were given.

### Archive and delete

| Action | Rule | Result |
|---|---|---|
| Archive | no request of the project is `queued` or `processing` | 409 `Film project {id} has generation running` |
| Unarchive | — | `status = active` |
| Delete | no request of the project is `queued` or `processing` | 409 `Film project {id} has generation running` |

- An archived project is read-only: every write on it, its episodes and scenes answers 409 `Film project
  {id} is archived`, except unarchive and delete.
- Delete removes the project, its links, episodes, scenes, requests and `storage/films/projects/{id}/`.
  Library characters, styles and voices stay.

## Data model — `Character` (table `film_characters`)

One reference entity of the library: a person, a place, a creature or a recurring object.

| Field | Type | Meaning |
|---|---|---|
| `id` | string(36) | UUID v4 |
| `name` | string(100) | trimmed; unique, case-insensitive, across the library |
| `entity_type` | enum | `character` \| `location` \| `creature` \| `visual_asset` \| `generic_troop` \| `faction` |
| `description` | text | appearance, 1–2000 characters |
| `image_prompt` | text | prompt of the reference image, 1–4000 characters; built at creation when left blank |
| `voice_description` | string(300) \| null | how the character sounds, e.g. `Deep gravelly voice with a warm laugh` |
| `style_id` | string(40) | → `film_styles.id`; the look of the reference image |
| `reference_status` | enum | `none` \| `queued` \| `processing` \| `done` \| `failed` |
| `reference_source` | enum \| null | `generated` \| `edited` \| `uploaded` \| `film_analysis` \| `film_clone` |
| `reference_path` | string \| null | `storage/films/characters/{id}/reference.{ext}` |
| `reference_error` | text \| null | set when `failed` |
| `provider_media` | JSON \| null | provider-side ids of the reference (e.g. a Flow `media_id`), written by providers |
| `origin_job_id` | string(36) \| null | the film analysis it was created from (4.2) |
| `origin_clone_id` | string(36) \| null | the film clone it was created from (4.2) |
| `created_at` / `updated_at` | datetime (UTC) | |

### Built `image_prompt`

When `image_prompt` is blank at creation it is built from the character and its style:

```
Reference image of {description}. {style_instruction} {negative_prompt} {composition} {lighting}
```

`{composition}` per `entity_type`:

| `entity_type` | Composition | Aspect |
|---|---|---|
| `character` | full body, head to toe, standing straight, centered, front-facing, neutral background | 9:16 |
| `location` | establishing shot of the whole place, level horizon, clear focal point, depth | 16:9 |
| `creature` | full body in its natural stance, centered, neutral background | 9:16 |
| `visual_asset` | the whole object, angle showing its features, centered, neutral background | 9:16 |
| `generic_troop`, `faction` | tactical pose, full or three-quarter body, centered, neutral background | 9:16 |

Editing `description`, `image_prompt` or `style_id` later keeps the current reference; the user
regenerates it to get the new look.

### Character rules

| Rule | Result |
|---|---|
| `name` trimmed is 1–100 characters | 400 `Character name must be 1-100 characters` |
| `name` unique, case-insensitive | 409 `A character named '{name}' already exists` |
| `description` 1–2000, `image_prompt` 1–4000 characters | 400 `Description must be 1-2000 characters` / `Image prompt must be 1-4000 characters` |
| `styleId` known | 400 `Style {id} not found` |
| Delete: linked to no project | 409 `Character '{name}' is used by {n} project(s)` |
| Delete, upload, generate: no reference request `queued` or `processing` | 409 `Character '{name}' has generation running` |
| Unknown character | 404 `Character {id} not found` |

Delete removes the row and `storage/films/characters/{id}/`.

### Links to projects (table `film_project_characters`)

Primary key (`project_id`, `character_id`), plus `created_at`.

| Action | Rule | Result |
|---|---|---|
| Link | character exists | 404 `Character {id} not found` |
| Link | already linked | 204, no change |
| Unlink | no scene of the project lists the character | 409 `Character '{name}' appears in {n} scene(s) of this project` |

A character whose `style_id` differs from the project's is allowed; the project page marks it
`Different style`.

### Reference image

Generation always runs in a project; the request takes the provider of `filmStudioImageProvider` (6.1).

| Action | Rule | Result |
|---|---|---|
| Generate / regenerate | character linked to the project | 409 `Character '{name}' is not in this project` |
| Edit with a prompt | `reference_status = done` | 409 `Character '{name}' has no reference image to edit` |
| Edit with a prompt | prompt trimmed is 1–2000 characters | 400 `Edit prompt must be 1-2000 characters` |
| Upload | `.jpeg .jpg .png .webp` | 400 `Unsupported image type '{ext}'. Use one of: .jpeg, .jpg, .png, .webp` |
| Upload | at most `FILM_UPLOAD_MAX_MB` | 413 `Image exceeds {N} MB` |
| Generate missing | — | queues one request per linked character whose status is `none` or `failed`; may return `[]` |

- Generate queues a `character_image` request (4.3) with `image_prompt` at the aspect of its
  `entity_type`; edit queues an `edit_image` request on the current reference. Both set
  `reference_status = queued`.
- Upload stores the file at once: `done`, `reference_source = uploaded`, `provider_media` cleared.
- A new reference keeps every scene image already made with the old one; the user regenerates those
  scenes to pick it up.

## Data model — `Style` (table `film_styles`)

| Field | Type | Meaning |
|---|---|---|
| `id` | string(40) | built-in: the slug below; custom: UUID v4 |
| `name` | string(50) | unique, case-insensitive |
| `is_builtin` | boolean | |
| `style_instruction` | text | 1–2000 characters |
| `negative_prompt` | text \| null | at most 1000 characters |
| `scene_prefix` | text \| null | at most 500 characters; put in front of every scene image prompt (4.3) |
| `lighting` | string(200) | default `Studio lighting, highly detailed` |

Built-in styles, written at API start when missing and read-only: `Photorealistic` (`realistic`), `3D Pixar`
(`3d_pixar`), `Anime` (`anime`), `Felt & Wood Stop Motion` (`stop_motion`), `Minecraft` (`minecraft`),
`Oil Painting` (`oil_painting`), `Studio Ghibli` (`ghibli`), `Watercolor` (`watercolor`), `Comic Book`
(`comic_book`), `Cyberpunk` (`cyberpunk`), `Claymation` (`claymation`), `LEGO` (`lego`), `Retro VHS`
(`retro_vhs`). Their texts live in the API code.

| Rule | Result |
|---|---|
| `name` trimmed is 1–50 characters | 400 `Style name must be 1-50 characters` |
| `name` unique, case-insensitive | 409 `A style named '{name}' already exists` |
| `style_instruction` trimmed is 1–2000 characters | 400 `Style instruction must be 1-2000 characters` |
| Edit or delete a built-in style | 409 `Built-in styles cannot be changed` |
| Delete: used by no project and no character | 409 `Style '{name}' is used by {p} project(s) and {c} character(s)` |
| Unknown style | 404 `Style {id} not found` |

## Data model — `VoiceTemplate` (table `film_voice_templates`)

A recording the speech provider imitates for narration (4.4). What each speech provider needs from it is in
7.5 § Speech.

| Field | Type | Meaning |
|---|---|---|
| `id` | string(36) | UUID v4 |
| `name` | string(64) | letters, digits, `-`, `_`; unique, case-insensitive |
| `description` | string(300) \| null | |
| `sample_path` | string | `storage/films/voices/{id}/sample.{ext}` |
| `sample_text` | text | the words spoken in the sample |
| `sample_duration_ms` | int | from `ffprobe` |
| `consent_path` | string \| null | `storage/films/voices/{id}/consent.{ext}` — the same speaker reading Google's consent statement; needed only by Google AI speech |
| `provider_voices` | JSON | the copy of the voice each provider made from it, e.g. `{ "elevenlabs": "…", "google": "…" }` (7.5) |
| `created_at` / `updated_at` | datetime (UTC) | |

| Rule | Result |
|---|---|
| `name` matches `^[A-Za-z0-9_-]{1,64}$` | 400 `Voice name must be 1-64 letters, digits, '-' or '_'` |
| `name` unique, case-insensitive | 409 `A voice named '{name}' already exists` |
| File `.wav .mp3 .m4a` | 400 `Unsupported audio type '{ext}'. Use one of: .m4a, .mp3, .wav` |
| File at most `FILM_UPLOAD_MAX_MB` | 413 `Audio exceeds {N} MB` |
| Sample 3–180 s long | 400 `Voice sample must be 3-180 seconds long` |
| Consent clip: `.wav .mp3 .m4a`, at most `FILM_UPLOAD_MAX_MB` | 400 / 413 as the sample |
| `sampleText` blank → whisper (as 1.2, language `auto`) finds speech | 400 `Could not transcribe the sample. Type its text instead` |
| Delete: narrator of no project | 409 `Voice '{name}' is the narrator of {n} project(s)` |
| Unknown voice | 404 `Voice {id} not found` |

- Transcription runs inside the upload request; the sample text stays editable afterwards.
- Uploading or deleting the consent clip empties `provider_voices.google`.
- Delete removes the row and `storage/films/voices/{id}/`.
