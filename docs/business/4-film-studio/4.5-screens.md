# 4.5 Screens

Part of [4. Film Studio](../4-film-studio.md). Header menu as in 1.7; every `/films…` page highlights
`Film Studio`. Under the header, Film Studio pages show the links `Projects` (`/films`) · `Library`
(`/films/library`).

An error from the API shows an alert with its `detail` and keeps what the user typed.

## `/films` — Projects

**Panel "Projects"**

- Switch `Active` (default) | `Archived`.
- Row: name (link to `/films/{id}`), frame badge `16:9` / `9:16`, style name, `{n} episodes`, updated time.
- Empty → `No projects yet` / `No archived projects`.
- `New project` opens the panel below.

**Panel "New project"**

| Element | Detail |
|---|---|
| `Name` | text, required |
| `Premise` | text area, hint `Sent to the AI model for every episode.` |
| `Language` | `Vietnamese` \| `English` \| `Japanese`; preselects the shared language preference of 1.7, `English` when that is `Auto-detect` |
| `Frame` | `Landscape 16:9` (default) \| `Portrait 9:16` |
| `Style` | built-in styles, then custom ones; `Photorealistic` preselected |
| `Default clip length` | `4 s` \| `6 s` \| `8 s` (default) \| `10 s`, hint `For scenes you add or copy from a film clone; the script picks each scene's length.` |
| `Characters speak in clips` | checkbox, on |
| `Narration` | checkbox, on; `Narrator voice` select (voices, or `—`) with link `Add a voice` → `/films/library?tab=voices` |
| `Background music` | checkbox, off |
| `Cast` | searchable multi-select of library characters |
| Media line | read-only `Images with: {provider name} · Clips with: {provider name}` — the providers `filmStudioImageProvider` and `filmStudioClipProvider` resolve to (6.1), with a link `Change` → `/settings?tab=film-studio` |
| Buttons | `Create`, `Cancel` |

- `Create` is enabled with a non-blank name and no request in flight; success → `/films/{id}`.

## `/films/{id}` — Project

- Header: name, badge `Archived` when archived, `Archive` / `Unarchive`, `Delete` → confirm `Delete project
  '{name}'? Its episodes and their files are removed; characters stay in the library.` → `/films`.
- An archived project shows the notice `This project is archived.`; every form and button is disabled
  except `Unarchive` and `Delete`.

**Panel "Settings"** — the fields of `New project` except `Cast`; `Save` is enabled with unsaved changes and
shows the notice `Saved`. `Frame` and `Style` are disabled with the hint `Fixed once a scene image exists`
when so.

**Panel "Cast"**

- One card per linked character: reference image or a placeholder, name, type badge, badge `Different style`
  when its style is not the project's, status `Queued` / `Generating…` / `Failed: {error}`.
- Card actions: `Generate` (`none`, `failed`) or `Regenerate` (`done`), `Edit image` (`done` — a dialog with
  `Edit prompt` and `Apply`), `Upload`, `Cancel` (while the character's request is `queued`, 4.3 § Cancel),
  `Remove from project`.
- `Add from library` → picker of characters not linked; `New character` → the character form of
  `/films/library`, linked on save.
- `Generate missing references ({n})` — `n` = linked characters whose reference is `none` or `failed`;
  disabled at 0.

**Panel "Episodes"**

- Row: `E{number}` · title (link to `/films/{id}/episodes/{number}`) · status badge · step label · duration
  (`mm:ss`, or `—`) · created time. Empty → `No episodes yet`.
- `New episode` opens the panel below.

**Panel "New episode"**

| Element | Detail |
|---|---|
| `Source` | `Idea` (default) \| `Film analysis` |
| `Idea` | text area; required for `Idea`, labelled `Extra direction (optional)` for `Film analysis` |
| `Film analysis` | `Film analysis` source only: the 50 newest `done` analyses as `{source_filename} · {created time}` |
| `Target length` | seconds, 8–600, default 60; hint `The script picks the number of scenes and each one's length, 4-30 s.` |
| `Pause after` | checkboxes `Script`, `Reference images`, `Scene images` (only the last ticked) |
| `Subtitles` | checkbox `Burn subtitles into the video`; `Subtitle style` select |
| `Prompt preset` | as 1.7, link `Edit presets` → `/settings?tab=prompt-override&id={selected}` |
| `AI` line | as 8.4 — the model that writes the script |
| Buttons | `Create and start` (default), `Create` |

- Buttons are enabled with the source's required input, a target within 8–600, a captcha token (when the
  captcha is on) and no request in flight. The captcha resets after every attempt.
- `Create and start` creates the episode, then starts it; `Create` leaves it `draft`. Both open
  `/films/{id}/episodes/{number}`. A refused start leaves the episode `draft` and the page shows the alert.
- The page refreshes every 3 s while an episode is `running` or a cast reference is `queued` / `processing`.
- Unknown id → `Project not found` with a link to `/films`.

## `/films/{id}/episodes/{number}` — Episode

- Header: `E{number} · {title}` (title editable in place unless `running`), status badge, link to the project.
- Buttons by status: `draft` → `Start`; `running` → `Stop`; `paused` → `Continue`; `failed` → `Resume`;
  `done` → `Assemble again`. `Rewrite script` when 4.2 allows it; `Delete` unless `running` → confirm
  `Delete episode {number}? Its scenes and files are removed.` → the project page.
- `done` with `needs_assembly` → notice `Scenes changed since the last assembly.` next to `Assemble again`.
- Stage list: the six stages of 4.2, each `completed` / `current` / `paused` / `failed` / `upcoming`.
  paused at a stop point adds `Paused after {stage label} — check the work, then Continue.` (not after `Stop`); `failed` shows an error alert
  with `error_message`.
- Counters: `Scenes {n} · Images {done}/{n} · Clips {done}/{n} · Narration {done}/{with text}`.

**Panel "Scenes"** — one card per scene, in order:

| Part | Shows | Actions |
|---|---|---|
| Title | `Scene {k}`, character chips | buttons on the card: `Insert scene after`, `Move up`, `Move down`, `Delete` (confirm `Delete scene {k}?`) |
| Image | the image (click to enlarge) or its status; `Pass {k} of {m}` while a request made in passes runs (7.1) | `Generate` / `Regenerate`, `Edit`, `Upload`, `Cancel` |
| Clip | a player or its status; `Part {k} of {m}` while a request made in segments runs (7.1) | `Generate` / `Regenerate`, `Cancel`; `Trim` → `Start (s)`, `End (s)`, `Save` |
| Narration | a player or its status; hidden with narration off | `Generate` / `Regenerate`, `Cancel` |
| Prompts | `Image prompt`, `Video prompt`, `Narration` text areas, `Clip length (s)` number field 4–30, `Characters` multi-select of the cast | `Save`, enabled with unsaved changes |

- A failed part shows its error under it.
- `Cancel` shows while the part's request is `queued` and cancels it (4.3 § Cancel); a refusal shows its
  error under the button.
- While `running`, every edit control is disabled with the hint `Stop the episode to edit.`
- `Add scene` closes the list. `Add scene` and `Insert scene after` open an unsaved card with empty prompt
  fields and the project's default clip length at that place; its `Save` creates the scene (4.3), `Cancel`
  drops the card.

**Panel "Script"** — `logline`; `Music prompt` with `Save`, the music status or a player, `Cancel` while the
music request is `queued`; `Thumbnail
prompt` with `Save`; `Prompt preset` as `{name} v{n}`; `AI` (8.4); `Source` = `Idea`, or a link to `/film-analysis/{id}`,
or to `/film-clone/{id}`, or `(deleted)`; collapsed `Prompt used` with the `filmScript` text read-only and `Copy`.

**Panel "Result"** — once `video_path` exists: player, duration, `Download video`, `Download subtitles`
(when an `.srt` exists). `Generate thumbnails` → four slots showing each candidate's status or image, `Use
this` on a ready one, `Cancel` on a `queued` one; the chosen thumbnail is shown with `Download thumbnail`.

- The page refreshes every 3 s while the episode is `running` or one of its requests is `queued` /
  `processing`.
- Unknown project or episode → `Episode not found` with a link to `/films`.

### Stage labels

| `step` | Label |
|---|---|
| `writing_script` | Writing script |
| `generating_references` | Generating reference images |
| `generating_scene_images` | Generating scene images |
| `generating_clips` | Generating clips |
| `generating_audio` | Generating narration and music |
| `assembling` | Assembling the film |

## `/films/library` — Library

Tabs `Characters` (default) · `Styles` · `Voices`; `?tab=characters|styles|voices` selects one.

**Characters**

- Hint `Generate reference images from a project's Cast panel.`
- Search by name, filter by type. Card: reference image or placeholder, name, type, style, `{n} projects`.
- `New character` → form `Name`, `Type`, `Description`, `Image prompt` (hint `Left blank, it is built from the
  description and style.`), `Voice description`, `Style`, `Save`. Clicking a card opens the same form with
  its values, `Upload reference` and `Delete` (confirm `Delete character '{name}'?`).

**Styles**

- Built-in styles first with badge `Built-in`, read-only; then custom styles by name.
- `New style` → form `Name`, `Style instruction`, `Negative prompt`, `Scene prefix`, `Lighting`, `Save`;
  a custom style opens the same form with `Delete`.

**Voices**

- Row: name, description, length, sample player, sample text, badge `Consent` when a consent clip is stored.
- `New voice` → form `Name`, `Description`, `Sample` file picker (`.wav .mp3 .m4a`), `Sample text` (hint
  `Left blank, the text is transcribed from the sample.`), `Consent clip` file picker (hint `Only Google AI
  speech needs it: the same speaker reads Google's consent statement.`), `Save`. A voice opens the same form
  without the `Sample` picker, with `Remove consent clip` when one is stored and `Delete`.

## From a film analysis

The `Make a film` panel on `/film-analysis/{id}` is specified in 3.6. It creates the project when a new one
is asked for, then the episode, with the rules of 4.1 and 4.2.

## From a film clone

The `Send to Film Studio` panel on `/film-clone/{id}` is specified in 5.6, with the same flow and source
`film_clone`.
