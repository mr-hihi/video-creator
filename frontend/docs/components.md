# Components

## Rules

- **Critical** — one exported component per file, file named after it (`JobStatusBadge.tsx`).
- **Critical** — props are an `interface <Name>Props`; extend the native element props when wrapping one (`Button` extends `ButtonHTMLAttributes` minus `className`).
- **Critical** — a control that must not be pressed twice is `disabled` while its action runs — no spinner on the button.
- **Preferred** — add `"use client"` only to components that use state, effects, refs or browser APIs.
- **Preferred** — reuse before creating: check `components/atoms/` and `components/molecules/` first.
- No Storybook and no component tests yet (see [testing-strategy.md](testing-strategy.md)).
